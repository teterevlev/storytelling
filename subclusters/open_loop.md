я изучаю сценарии к видео. я разбиваю их на story beat. сейчас я тебе пришлю выборку разных OPEN_LOOP - Открытие конкретной интриги/загадки, ответ на которую будет дан позже (не путать с QUESTION_STACK — здесь фиксируется конкретный обещанный факт).

**Важно:** полностью игнорируй тему, сюжет, исторический период, персонажей, объекты, страны и любые фактические детали. Не группируй примеры по содержанию.

Твоя задача — найти **естественные кластеры**, объединяя примеры **исключительно по психологическому механизму**, с помощью которого они вызывают желание продолжить просмотр.

Под психологическим механизмом понимается не текст, не сюжет и не стиль формулировки, а общий принцип воздействия на зрителя. Если два примера используют один и тот же принцип, они должны оказаться в одном кластере, даже если их содержание полностью различается.

Не учитывай повторяющиеся слова, синтаксис, вводные конструкции и характерные обороты речи. Представь, что каждый пример полностью перефразирован другими словами. Если после такой переформулировки механизм останется тем же, примеры принадлежат одному кластеру. Если изменится — разным.

Не стремись получить заранее заданное количество кластеров. Лучше создать больше небольших кластеров, чем объединить разные механизмы в один.

Если пример не имеет явного сходства ни с одним другим, не пытайся искусственно включить его в существующий кластер. Создай отдельный кластер или помести его в раздел **«Временно неклассифицированные»**.

Не придумывай названия кластерам. Не используй существующие термины из риторики, сценарного мастерства или психологии. На этом этапе названия запрещены.

Для каждого кластера выведи:

1. Номер кластера.
2. Одно предложение, начинающееся словами:
   **«Все эти примеры работают одинаково, потому что...»**
3. Абстрактную формулу механики в виде короткой последовательности шагов без привязки к конкретным сюжетам.
4. Список номеров примеров, входящих в кластер.
5. Если какой-либо пример подходит сразу к нескольким кластерам, укажи основной кластер и дополнительные.
6. Ответ на вопрос:
   **«Почему эти примеры нельзя разделить как минимум на два разных кластера?»**

Правила:

* Лучше разделить похожие механики, чем объединить разные.
* Кластер может состоять из одного примера, если его механизм действительно уникален.
* Не стремись к одинаковым размерам кластеров.
* Не оценивай качество примеров.
* Не предлагай улучшений.
* Не придумывай новых примеров.
* Не объясняй, как можно использовать получившиеся кластеры.

после этого у просмотри получившиеся кластеры. возможно, какие-то кластеры окажутся недостаточно однородными. их надо будет кластеризовать заново по тем же правилам, создав новые кластеры. в то же время, в первом, и особенно во втором прогоне могут появиться кластеры, которые скорее можно отнести к остатку классификации, нежели к самостоятельным кластерам. их надо объединить и попробовать кластеризовать заново. если после этого останутся неклассифицированные, это уже нормально.

Результатом должна стать максимально детальная естественная кластеризация по психологическим механизмам без их именования.

Потом уже отдельной итерацией: Для каждого кластера придумай максимально короткую формулу.

Еще одной итерацией: придумай название.

Вот что получилось для Open Loop

Кластер 1 — скрытый факт / скрытый элемент

Формула:

Есть объект X
→ у него существует неизвестный элемент Y
→ Y имеет решающее значение
→ раскрытие Y позже

Абстрактно:

"Вы знаете X. Но вы не знаете главного — Y."

Кластер 2 — эскалация / следующий уровень

Формула:

Текущий уровень проблемы X
→ сигнал: это не максимум
→ существует более сильный уровень Y
→ переход к Y

Абстрактно:

"Это было только начало."

Кластер 3 — демонстрация / проверка

Формула:

Есть утверждение или объект X
→ предлагается посмотреть на него через действие
→ действие выполняется
→ появляется результат

Абстрактно:

"Давайте проверим, что произойдет, если..."

Кластер 4 — скрытый метод решения

Формула:

Есть задача X
→ существует способ решения Y
→ способ пока неизвестен
→ раскрытие Y позже

Абстрактно:

"Проблема кажется невозможной. Но существует способ."

Кластер 5 — цель без пути

Формула:

Есть конечный результат X
→ результат уже обозначен
→ неизвестно, как его достичь
→ раскрытие пути позже

Отличие от 4:

4: "есть проблема, есть решение"
5: "есть достижение, неизвестен путь"
Кластер 6 — количественный ответ

Формула:

Есть неизвестная величина X
→ её можно вычислить
→ зритель ждёт значение
→ появляется число/оценка

Абстрактно:

"Сколько это на самом деле?"

Кластер 7.1 — скрытая причина

Формула:

Есть наблюдаемый эффект X
→ причина неизвестна
→ причина существует
→ объяснение причины позже

Абстрактно:

"Почему это произошло?"

Кластер 7.2 — скрытый принцип работы

Формула:

Есть объект/явление X
→ он работает определенным образом
→ механизм работы неизвестен
→ объяснение механизма позже

Абстрактно:

"Как это вообще работает?"

Кластер 7.4 — разрушение представления

Формула:

Есть распространенное представление X
→ оно недостаточно или неверно
→ существует более точная картина Y
→ раскрытие Y

Абстрактно:

"Вы думаете, что знаете X. Но всё сложнее."

Кластер 8 — смена перспективы

Формула:

Есть объект X
→ предлагаем посмотреть с новой позиции P
→ новая перспектива меняет понимание X

Абстрактно:

"Посмотрите на это глазами..."

Кластер 9 — исключение вариантов

Формула:

Есть несколько ожидаемых объяснений X1, X2...
→ они исключаются
→ остается неожиданный вариант Y

Абстрактно:

"Все думали, что это было X. Но оказалось Y."

Кластер 10 — незавершенный результат

Формула:

Есть процесс X
→ процесс начат
→ исход неизвестен
→ ожидание завершения

Абстрактно:

"Что получится в итоге?"

Кластер 11 — отложенный эпизод

Формула:

Существует событие X
→ событие обозначено
→ подробности события не рассказаны
→ рассказ позже

Абстрактно:

"Была одна история..."

Кластер 12 — скрытый масштаб

Формула:

Зритель оценивает X как небольшое явление
→ показывается, что X является частью большего Y
→ раскрывается настоящий масштаб

Абстрактно:

"Вы видите только верхушку."

Кластер 13 — странное решение

Формула:

Есть результат X
→ решение кажется необычным или нелогичным
→ существует рациональное объяснение выбора Y
→ раскрытие логики Y

Абстрактно:

"Почему они сделали именно так?"

Кластер 14 — внутреннее устройство

Формула:

Есть сложный объект X
→ внешнее описание недостаточно
→ предлагается проникнуть внутрь структуры
→ раскрывается устройство X

Абстрактно:

"Что находится внутри?"

Кластер 15 — значимость объекта

Формула:

Называется объект X
→ утверждается, что X необычен/важен
→ объясняется, почему X заслуживает внимания

Абстрактно:

"Почему именно этот объект стал героем?"

Кластер 16 — сравнение вариантов

Формула:

Есть вариант X
→ появляется вариант Y
→ зритель ждёт различие между ними
→ сравнение раскрывает смысл

Абстрактно:

"Что изменится, если вместо X будет Y?"

Кластер 17 — незавершенное действие

Формула:

Начинается действие X
→ действие не завершено
→ возникает ожидание результата
→ завершение позже

Абстрактно:

"Мы начали делать X. Посмотрим, что получится."

Кластер 18 — неизвестный масштаб

Формула:

Есть скрытая величина X
→ зритель хочет оценку масштаба
→ появляется конкретное значение Y

Отличие от 6:

6 — любой расчет;
18 — именно цена/размер/масштаб.
Кластер 19 — парадокс / нарушение правила

Формула:

Есть ожидание X
→ появляется факт Y, противоречащий X
→ объяснение противоречия

Абстрактно:

"Это должно было работать так. Но произошло наоборот."
